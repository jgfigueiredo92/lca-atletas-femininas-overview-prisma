# Revisões sistemáticas sobre lesão do LCA em atletas do sexo feminino

Conjunto de dados suplementar do resumo expandido submetido à SNCT 2026 (IF Baiano, Campus Alagoinhas).

Visão geral (overview) de revisões sistemáticas, relatada conforme PRISMA 2020 (Page et al., 2021, https://doi.org/10.1136/bmj.n71). Busca no PubMed em 09/11/2026.

## Arquivos
- `SNCT2026_revisoes_LCA_atletas_femininas.xlsx`: abas LEIA-ME, Revisões incluídas (29), Triagem (148), Critérios, Fluxo PRISMA e Busca.
- `triagem_148_registros.csv`: registro de decisão e motivo de cada registro (UTF-8).

## Fluxo
148 identificados; 0 duplicatas; 49 excluídos por data (< 2020); 99 avaliados; 70 excluídos (E1 7; E2 13; E3 7; E4 42; E6 1); 29 incluídos.

## Limitações
Uma base; triagem e extração por título e resumo com apoio do assistente de IA Claude, sem segundo revisor independente; sem avaliação do risco de viés; sobreposição de estudos primários não quantificada; recorte 2020–2026 definido após a busca.
